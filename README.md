# sistema-bancario-pytho
Este projeto simula um **sistema bancário** com funcionalidades de **depósito**, **saque** e **extrato**, desenvolvido como parte do desafio da DIO para praticar lógica de programação em Python.

## Funcionalidades

- **Depósito:** Adiciona um valor à conta.
- **Saque:** Permite sacar até 3 vezes ao dia, com limite de R$500 por saque.
- **Extrato:** Mostra todas as movimentações da conta e o saldo atual.

## Regras do Sistema

- O limite diário de saques é **3 operações**.
- O valor máximo por saque é de **R$500,00**.
- Não é permitido sacar valores maiores que o saldo disponível.
- O extrato mostra todos os depósitos e saques realizados.
